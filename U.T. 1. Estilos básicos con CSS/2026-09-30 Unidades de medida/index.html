Unidades de medida

Unidades absolutas

  • Píxel (px)
  • Punto (pt)
  • Centímetro (cm)
  • Milímetro (mm)

Unidades relativas

vh y vw
Viewport height y Viewport Width. En principio, solo se usan con la etiqueta body.
dvh y dvw
Dynamic Viewport height y Dynamic Viewport Width. En principio, solo se usan con la etiqueta body.
El porcentaje (%)
El tamaño cuando usamos el porcentaje se calcula siempre de forma relativa a la etiqueta padre.
rem
La unidad Root em usa como valor base el tamaño establecido en la pseudoclase :root. Por defecto es 16px. Se usa normalmente para caracteres.
